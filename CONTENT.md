# Как менять данные сайта

Весь редактируемый контент находится в папке `content/`. Компоненты React менять не нужно.
После изменения файлов достаточно заново собрать сайт командой `npm run build`.

## Структура

```text
content/
├── projects/
│   └── medtech/
│       ├── project.json
│       └── journal/
│           └── 2026-07-27.md
├── publications.json
└── timeline.json
```

## Проекты

Каждый проект — отдельная папка внутри `content/projects/`.

Файл `project.json`:

```json
{
  "slug": "medtech",
  "title": "MedTech",
  "description": "Короткое описание проекта.",
  "status": "В разработке",
  "started": "2026-06-12",
  "updated": "2026-07-27",
  "tags": ["машинное обучение", "медицина"]
}
```

### Обязательные поля

- `slug` — уникальное имя проекта на английском, совпадает с названием папки.
- `title` — название карточки.
- `description` — короткое описание в 1–2 предложения.
- `status` — `В разработке`, `Выпущен` или `Архив`.
- `started` — дата начала в формате `YYYY-MM-DD`.
- `updated` — дата последнего изменения в формате `YYYY-MM-DD`.
- `tags` — массив коротких тематических тегов.

### Дополнительные поля

Для выпущенного проекта:

```json
"version": "0.4.0",
"link": "github.com/Takhmazyan-Lab/example"
```

Для архивного проекта:

```json
"reason": "Почему проект закрыт.",
"conclusion": "Что удалось понять и сохранить."
```

## Журнал разработки

Создавайте внутри проекта папку `journal/`. Каждая запись — отдельный Markdown-файл с датой в имени:

```text
content/projects/medtech/journal/2026-08-01.md
```

Внутри достаточно короткого текста:

```md
Добавлена поддержка локального поиска.
```

Дата из имени файла используется на сайте автоматически. Новые записи не требуют изменения `app/page.tsx`.

## Публикации

Публикации хранятся в `content/publications.json`:

```json
{
  "date": "2026-08-01",
  "type": "Заметка",
  "title": "Название материала",
  "description": "Короткий анонс публикации."
}
```

Добавьте объект в массив, не забывая запятую между соседними объектами.

## Лента активности

Лента хранится в `content/timeline.json`:

```json
{
  "date": "2026-08-01",
  "kind": "журнал",
  "title": "MedTech",
  "text": "Добавлена поддержка локального поиска."
}
```

Элементы отображаются сверху вниз в порядке, указанном в файле. Новые записи добавляйте в начало массива.

## Рекомендации

- Используйте даты только в формате `YYYY-MM-DD`.
- Проверяйте JSON после ручного редактирования: лишняя запятая сломает сборку.
- Делайте записи журнала конкретными и короткими.
- Не удаляйте архивные проекты — они являются частью истории лаборатории.
- После изменений проверяйте сайт командами `npm run build` и `npm run dev`.
