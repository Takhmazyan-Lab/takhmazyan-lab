# Краткое пособие по сайту

## Что где находится

- `app/page.tsx` — структура страниц и отображение данных. Здесь не нужно менять тексты проектов.
- `app/globals.css` — визуальная система, сетка, адаптивность и состояния карточек.
- `content/projects/` — проекты лаборатории.
- `content/publications.json` — публикации и заметки.
- `content/timeline.json` — общая лента активности.

## Как добавить проект

1. Создайте папку `content/projects/my-project/`.
2. Добавьте `project.json`:

```json
{
  "slug": "my-project",
  "title": "Название проекта",
  "description": "Короткое описание проекта.",
  "status": "В разработке",
  "started": "2026-08-01",
  "updated": "2026-08-01",
  "tags": ["эксперимент"]
}
```

3. Создайте папку `journal/` и добавляйте в неё записи в формате `YYYY-MM-DD.md`.
4. Для выпущенного проекта добавьте `version` и `link`.
5. Для архива добавьте `reason` и `conclusion`. Проект автоматически появится в разделе «Архив».

## Статусы

- `В разработке` — рабочая карточка с журналом.
- `Выпущен` — карточка с версией и ссылкой.
- `Архив` — отдельный раздел с причиной закрытия, выводом и полным журналом.

После изменения JSON или Markdown перезапустите dev-сервер, если Next.js не подхватил файл автоматически.

## Полезные советы

- Делайте записи журнала короткими: одно изменение или наблюдение на файл.
- Не удаляйте закрытые проекты: архив сохраняет историю и контекст решений.
- Обновляйте поле `updated` одновременно с последней записью журнала.
- Для больших материалов используйте `content/publications.json`, а не карточки проектов.
